# Smart-Factory-IOT-Monitoring-System


📌 Overview
A Smart Factory IoT Monitoring System developed for real-time industrial monitoring using IoT technology.  
The system monitors factory parameters like temperature, humidity, machine status, vibration, and relay control through an IoT dashboard.


## 🎯 Features
✔️ Real-time Monitoring  
✔️ Temperature & Humidity Tracking  
✔️ Machine Status Detection  
✔️ Relay/Switch Control  
✔️ Alarm & Alert System  
✔️ Warehouse Monitoring  
✔️ Live Dashboard Visualization  


## 🛠️ Technologies Used
1. IoT  
2. ESP32 / NodeMCU  
3. Sensors  
4. Arduino IDE  
5. ThingsBoard Dashboard  
6. Embedded C  


## ⚙️ Modules
### 1️⃣ Production Line Monitoring
